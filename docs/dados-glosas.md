# Fontes para reconhecimento de glosas em Libras contínua

Triagem de 26 de novembro de 2026. O ensaio requer gravações contínuas de pessoas sinalizantes, uma sequência ordenada de glosas anotadas sobre a sinalização produzida, texto em português associado ao mesmo trecho e um identificador estável de pessoa para separar treino, validação e teste. Fronteiras por glosa são necessárias para medir IoU. O reconhecimento de uma sequência inteira pode ser medido com referência ordenada, mesmo quando a fonte não oferece fronteiras. A licença e as condições de acesso precisam abranger o recorte usado no ensaio.

Nenhuma fonte verificada reuniu esses requisitos com acesso liberado para este trabalho. O Captar-Libras documenta todos os componentes e tem acesso sujeito a aprovação nas duas distribuições. Esta triagem não gerou recortes, partições nem resultados de modelo com glosas.

## Reprodução da checagem do EQT

Com os `train.npy`, `dev.npy` e `test.npy` oficiais já baixados conforme o [ensaio de sinalização contínua](sinalizacao-continua.md), execute desde a raiz com o ambiente Python do projeto ativo. O leitor confere o SHA-256 dos três arquivos antes de abrir as anotações.

```sh
python - <<'PYCODE'
from pathlib import Path

from ml.continuous_experiment.eqt import SPLITS, load_annotations

for split in SPLITS:
    rows = load_annotations(Path("data/eqt-v4"), split)
    labels = [row["original_info"][0] for row in rows]
    portuguese = sum(bool(label["label_char"]) for label in labels)
    glosses = sum(bool(label["label_gloss"]) for label in labels)
    print(f"{split} total={len(labels)} português={portuguese} glosas={glosses}")
PYCODE
```

## Recorte para uma eventual aquisição autorizada

Para Captar-Libras, o primeiro recorte pode usar a câmera frontal e preservar as três listas oficiais por pessoa. A verificação começa com as anotações e pelo menos uma gravação original de cada partição para conferir tempo, ordem das glosas e associação com o texto. O manifesto local deve fixar a revisão da distribuição, o identificador da gravação e da pessoa, a checagem de integridade e a partição. Pessoas e gravações da validação e do teste ficam fora dos ajustes. O teste de generalização a novas frases exigirá um desenho adicional, pois as partições oficiais separam pessoas e o protocolo usa um repertório compartilhado. [Protocolo e modalidades oficiais](https://verlab.github.io/captar-libras/)
